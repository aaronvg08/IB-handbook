# Tipos de areas

- Disciplinas
    - Tienen solamente un objeto de conocimiento.
    - Por ejemplo: Biología, Historia, etc.
- Multidisciplinas
    - Más de un objeto de conocimiento.
    - Combinar dos métodos distintos, dos disciplinas.
    - Por ejemplo: bio-quimica, fisico-matemáticas.
- Interdisciplinas
    - Conjugación de varias areas para resolver un problema.
    - Aplicadas a problemas, siempre.
    - Por ejemplo: biotecnología, arquitectura.
- Transdisciplinas
    - Algo que esta en todas las disciplinas.
        - Casi casi un lenguaje aparte, como para representar lo posible.
        - Una herramienta para las demás disciplinas.
    - Ejemplo: Mátematicas, composición musical, el arte.
