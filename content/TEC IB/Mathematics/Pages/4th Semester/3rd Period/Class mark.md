The class mark is a value only used in [[Statistics#Grouped data|grouped data]] in statistics. It is the average of the upper and lower intervals that the class is in.

For example, consider the following dataset.

|     |     | Grades |     |     |
| --- | --- | ------ | --- | --- |
| 90  | 90  | 50     | 60  | 80  |
| 80  | 84  | 95     | 89  | 76  |
| 75  | 50  | 55     | 68  | 90  |
| 100 | 80  | 97     | 100 | 100 |
After splitting the dataset into classes, the class marks would be the following.

| Num | Lower boundary | High boundary | Class mark |
| --- | -------------- | ------------- | ---------- |
| 1   | 50             | 60            | 55         |
| 2   | 60             | 70            | 65         |
| 3   | 70             | 80            | 75         |
| 4   | 80             | 90            | 85         |
| 5   | 90             | 100           | 95         |
