The mode is a [[Central tendency measures|central tendency measure]] that tells you the most repeated value in a dataset. This is the only central tendency measure that can be used with data that aren't numbers.

# Example

For example, take the following dataset.

$$
a=\{5,1,1,1,10,94,21,1,4\}
$$

Here, the mode is $1$ since it is repeated 4 times.
