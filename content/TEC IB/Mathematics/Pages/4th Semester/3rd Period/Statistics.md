# Grouped data

Grouped data in statistics refers to data that we have separated and grouped into certain intervals. It is more useful to group data before treating it at times, since it can give us an insight into how the values are behaving. Ungrouped data looks something like this.

|     |     | Grades |     |     |
| --- | --- | ------ | --- | --- |
| 90  | 90  | 50     | 60  | 80  |
| 80  | 84  | 95     | 89  | 76  |
| 75  | 50  | 55     | 68  | 90  |
| 100 | 80  | 97     | 100 | 100 |
While grouped data looks like this.

| Num | Lower boundary | High boundary | Frequency | Class mark |
| --- | -------------- | ------------- | --------- | ---------- |
| 1   | 50             | 60            | 3         | 55         |
| 2   | 60             | 70            | 2         | 65         |
| 3   | 70             | 80            | 2         | 75         |
| 4   | 80             | 90            | 5         | 85         |
| 5   | 90             | 100           | 8         | 95         |
For grouped data, you use different formulas. For those formulas, you must have the following things in mind:

- [[Frequency (statistics)|Frequency]]
- [[Class mark]]
- [[Deviation]]

To turned ungrouped data into grouped data, you must separate them into classes. You can use [[Sturges' rule]] to know the amount of classes you need and use the formula for the [[Class amplitude|amplitude]] to know how big the lower and higher boundary should be.
