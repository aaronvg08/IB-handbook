A polyhedron is a three-dimensional [[Polygon|polygon]]. It has straight edges and sharp corners or vertices. Some common polyhedra are the following.

- [[Tetrahedron]]
- [[Hexahedron]]
- [[Octahedron]]
- [[Dodecahedron]]
- [[Icosahedron]]

# Standardized

Standardized polyhedra are common polyhedrons that have the same formula for all of them. It is a good way to catalog polyhedra so that you don't have to memorize one for each (or create a separate note for each smh).

There are three standardized polyhedra:

- [[Prism|Prisms]]
- [[Pyramids]]
- [[Spheres]]
