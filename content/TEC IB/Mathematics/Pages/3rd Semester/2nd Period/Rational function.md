A rational function is a type of [[Function|function]] that has a [[Rational expression|rational expression]] on it, so a  on it. A rational function may look something like this:

$$
f(x)=\frac{2x+3}{x-4}
$$

> [!warning]
> Beware! Not all functions with fractions are rational functions. Some cancel out and turn into [[Quadratic function|quadratic functions]], [[Linear function|linear functions]], or worse, [[Constant function|constant functions]].

# Graph

A rational function's graph is special because it involves an [[Asymptote|asymptote]]. For example, consider the following function.

$$
f(x)=\frac{1}{x}
$$

The graph of his function would look something like this:

![[rational function.png|center|450]]

The thing in the middle, where the curve goes towards $\infty$ and $-\infty$ is called the [[Asymptote|asymptote]]. This happens because a division cannot be done with zero, so as $x$ approaches zero (or a value that makes the denominator of the fraction zero), the function does weird things.

# Domain & range

- The [[Domain|domain]] for a rational function is always an interval of ($\infty,-\infty$) avoiding the vertical asymptote, so where the $\text{denominator}=0$.
- The [[Range (functions)|range]] for a rational function depends. 
	- For a rational homographic function, which is to say a $\frac{linear}{linear}$ or $\frac{constant}{linear}$ function, is an interval of ($\infty,-\infty$) except avoiding the horizontal asymptote.
	- For any other type of rational, you need the graph, or its [[Inverse function|inverse]] if it's injective.
