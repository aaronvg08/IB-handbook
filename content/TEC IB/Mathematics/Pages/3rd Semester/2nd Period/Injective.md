When a function is injective, it means that for every $y$ value, there is only one $x$ value. Another way of viewing it is that you cannot get an output with more than one input. So, each input and output is unique.

# Horizontal line test

In order to test if a function is injective or non-injective, you can try to draw a horizontal line on a function and see if it only hits one point.
