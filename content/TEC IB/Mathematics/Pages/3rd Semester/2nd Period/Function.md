A function in math is similar to a function in [[computer science]]. It is a mathematical relationship where each value ($x$) is assigned to an output ($y$). A function may look something like this:

$$
f(x)=2x-3
$$

# Functions vs relations

If we define a function, both in math and programming, we always expect a unique result for each unique value. If a function in $x$ ends up having two values on $y$, then it is not a function. It is a relation.

![[function vs relation.png|center|500]]

> [!note] All functions are relations, but not all relations are functions!

## Vertical line test

A simple way to verify if a graph is representing a function or a relation is to draw a vertical line. If the line touches two or more points on its way towards $-\infty$, then it is a relation. Otherwise, it is a function.

![[fun vs rel graphs (no lines).png|center|650]]

# Evaluating functions

It is useful to think of functions as machines that have special jobs. For example, think of the following function:

$$
f(x)=x+10
$$

Evaluating this function would look something like this:

$$
f(16)=16+10
$$
$$
f(16)=26
$$

# Types

There can be a multitude of types of functions, each one named and described after a specific characteristic of it. A function can be even or odd, and there are three types: algebraic, trascendental, and trigonometric.

## Odd & even (HL)

- A function is even only if $f(-x)=f(x)$.
- A function is odd only if $f(-x)=-f(x)$.
