A constant function is a [[Function|function]] that is defined only with a constant, which is to say any number, and nothing else. No $x$, or any other variable. A constant function may look something like this:

$$
f(x)=5
$$

# Graph

Graphically, a constant function is simply a straight line that starts at the $y$ value of the constant itself. For example, for the following function,

$$
f(x)=\pi
$$

The graph would look something like this:

![[constant function.png|center|450]]

 It's a straight, horizontal line. Due to this, as it is true for all horizontal lines, the [[Slope]] of a constant function is $0$.
# Domain and range

- The [[Domain]] for a constant function is always going to be $(-\infty,\infty)$, since all inputs are still possible (even if the variable isn't used!)
- The [[Range (functions)]] for a constant function is always going to be the constant, since the only output possible is just that.
