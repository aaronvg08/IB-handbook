Y reflection is a [[Function transformation|function transformation]] that allows you to create a new function as if the $y$ axis was a mirror.

![[x reflection.png|center|500]]

You do so in the following way.

$$
f(x)\cdot(-1)
$$

>[!example]
>With the function $f(x)=2x^{2}-5$, the new function would be $f(x)=-2x^{2}+5$.
