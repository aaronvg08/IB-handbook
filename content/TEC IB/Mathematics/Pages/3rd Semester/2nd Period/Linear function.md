A linear function is a type of [[Function|function]] that draws a straight line. It usually finds itself in the following format:

$$
y=mx+b
$$

Where $m$ is the [[Slope]] and $b$ is the y-intercept.

# Graph

As stated before, linear functions are straight lines. Whether the slope is negative or positive indicates whether the line is heading upwards, or downwards. For example, consider the following function.

$$
f(x)=4x+2
$$

![[linear function.png|center|450]]

As you can see, the value $b$ determines the y-intercept, and the [[Slope]] determines how much the function scales upwards.

# Domain & range

- The [[Domain|domain]] for a linear function is always $(-\infty,\infty)$, because all inputs are possible.
- The [[Range (functions)|range]] for a linear function is always $(-\infty, \infty)$, because all outputs are possible.
