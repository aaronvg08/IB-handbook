An exponential function is a type of [[Function|function]] that has an exponent and $x$ in one of those exponents. An exponential function may look something like this:

$$
f(x)=2^{x}+9
$$

# Graph

An exponential function's graph is an upward-sloping curve. Consider the following function.

$$
f(x)=2^{x}
$$

This function, when graphed, looks something like this:

![[exponential function.png|center|450]]

Notice how the function never goes into the negative $y$ axis? That is because a squared value can never be negative!

# Domain & range

- The [[Domain|domain]] of an exponential function is always the domain of the exponent.
- The [[Range (functions)|range]] of an exponential function is $(0,\infty)$ if it is positive, and $(-\infty,0)$ if it is negative.
