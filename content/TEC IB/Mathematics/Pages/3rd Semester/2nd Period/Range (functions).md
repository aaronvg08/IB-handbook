The range of a [[Function|function]] is how many possible outputs a function may have. Visually, it means how much space of the $y$ axis the function can cover.

>[!tip]
>The range of a function is the [[Domain|domain]] of its [[Inverse function|inverse]], though only when it's [[Injective|injective]].

# Graph

How you get the range of a function depends on the type of function it is, but if you have the graph, you can check how much the $y$ axis covers, and determine the range. So, for example, take the following graph.

![[linear function.png|center|450]]

This graph shows us that the domain is $(-\infty,\infty)$, since the graph touches every single $y$ axis point at some value. Now, take a look at the following graph.

![[rational function.png|center|450]]

This function never touches the point 0 at the $y$ axis. Therefore, the range for this function is $(-\infty,0)\cup(0,\infty)$.
