The domain of a [[Function|function]] is all the possible inputs a function may have. Visually, it means how much space of the $x$ axis the function can cover. 

>[!tip]
>The domain of a function is the [[Range (functions)|range]] of its [[Inverse function|inverse]], though only when it's [[Injective|injective]].

# Graph

How you get the domain of a function depends on the type of function it is, but if you have the graph, you can check how much the $x$ axis covers, and determine the range. So, for example, take the following graph.

![[linear function.png|center|450]]

This graph shows us that the domain is $(-\infty,\infty)$, since the graph touches every single $x$ axis point at some value. Now, take a look at the following graph.

![[rational function.png|center|450]]

This function never touches the point 0 at the $x$ axis. Therefore, the domain for this function is $(-\infty,0)\cup(0,\infty)$.
