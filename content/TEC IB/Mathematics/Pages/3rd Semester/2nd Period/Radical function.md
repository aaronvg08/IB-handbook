A radical function is a type of [[Function|function]] that, as its name indicates, has a radical inside of it. A radical function may look something like this:

$$
f(x)=\sqrt{ 9-x{^2} }
$$

# Graph

The graph of a radical function normally never touches the negative axis, and stems off like a plant would. Consider the following function.

$$
f(x)=\sqrt{ x }
$$

This function, when graphed, looks something like this:

![[radical function.png|center|450]]

The function, because it has a radical, never touches the quadrants where the numbers become negative, since that would make the solutions imaginary.

# Domain & range

- The [[Domain|domain]] for a radical function depends.
	- If it is an even radical, then it is when the $inner\;function\geq 0$.
	- If it is an odd radical, then it is always $(-\infty,\infty)$.
- The [[Range (functions)|range]] for a radical function must be obtained through its graph, or its [[Inverse function|inverse]] if it's injective.
