Vertical displacement is a [[Function transformation|function transformation]] that allows you to move a function up or down on the $y$ axis. 

![[vertical displacement.png|center|500]]

You do so in the following way.

$$
f(x)\pm K
$$

Where $K$ is the number of units you want to move the function.

>[!example]
>With the function $f(x)=3x^{2}$, to move it 5 units up, the new function would be $f(x)=3x^{2}+5$.
