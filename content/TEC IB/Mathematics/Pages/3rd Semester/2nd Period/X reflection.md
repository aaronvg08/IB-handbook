X reflection is a [[Function transformation|function transformation]] that allows you to create a new function as if the $x$ axis was a mirror.

![[y reflection.png|center|500]]

You do so in the following way.

$$
f(-x)
$$

>[!example]
>With the function $f(x)=10x+5$, the new function would be $f(x)=-10x+5$.
