Proof by counterexample is a type of [[Proof|proof]] that doesn't actually demonstrate that a statement is true. It does the opposite, it proves that a statement is false by finding a case for which it is false.

>[!example]
>Consider the set of numbers $P$ that is $n^{2}+41n+41$, where $n$ is a natural number. To disprove that not elements of $P$ are prime, we need to find a value of $n$ for which the result isn't prime.
>
>Let's try $n=41$.
>$$
>41^{2}+41(41)+41=3403
>$$
>
>This number isn't prime! It's divisible by 41 and 83. Therefore, the statement is false.
