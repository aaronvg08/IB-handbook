Variations are a type of [[Combinations and permutations|combinatoric]]. They are a way to count the possible arrangements in a set where repetition isn't allowed but order matters.

$$
aPb=\frac{a!}{(a-b)!}
$$
- $a$: Number of elements.
- $b$: Number of subsets.
- $aPb$: Permutations of $a$ elements in $b$ subsets.

>[!tip]
>If the number of elements is the same as the number of subsets, you can just calculate the [[Factorial|factorial]] of the elements instead of using the formula.
