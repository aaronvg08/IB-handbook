File management is one of the features of an [[Operating system (OS)]]. The OS is responsible for storage, retrieval, organization and manipulation of data and files inside the computer. There are the following features in file management.

- Hierarchical and logical file system.
- Extensions (.jpg, .pdf, etc.) to ensure consistency and avoid conflicts.
- **Basic operations**
	- Create
	- Write
	- Read
	- Delete
	- Rename

# Defragmentation

The process of reorganizing data of the same file that is not stored in continuous blocks. This improves speed access and system performance.
