Resource management is one of the main roles of the [[Operating system (OS)|operating system]]. It means to manage the computer resources efficiently.

- **CPU management**: Allocating CPU time to various processes.
- **Memory management**: Allocating memory for application.
	- When you open an application in the OS, it searches for it in the storage devices -> runs it and loads it into the RAM -> manages memory by allocating and de-allocating space for the program as needed.
	- You can do [[Virtualization|virtualization]] if you need it.
- **Storage management**: Organizing data into storage devices.
- **Device management**: Controlling and coordinating hardware devices.
