RGB is a way to represent color in screens. A Mexican computer scientist once realized, long ago, that we can create any color we wanted if we combined red, green, and blue. And so he tested it out, and it worked! Now, it is one of many ways to generate colors.

As you can see from the diagram, the following RGB operations exist:

- **Red + Green:** Yellow
- **Red + Blue:** Magenta
- **Green + Blue:** Cyan
- **Green + Red + Blue:** White

![[RGB.png|center|500]]

To generate these and many more colors, RGB varies the intensity of each light. RGB encodes each color intensity using 8 [[Bit|bits]]. Intensities vary from 0 to 255, since that is the max amount of number you can represent with just 8 bits.
