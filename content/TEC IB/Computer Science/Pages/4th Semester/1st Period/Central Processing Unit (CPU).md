The Central Processing Unit (CPU) is the most important component in a computer. It is basically the brain of the system, responsible for executing instructions. It works together with the rest of the components to manage the system and move data.

Within itself it contains components, registers, and buses.

# Components

A component in a CPU refers to a functional unit or part within it that has a specific role in the operation of the processor. The CPU contains key components which work together to execute instructions.

Key components in the CPU include:

- [[Arithmetic Logic Unit (ALU)]].
- [[Control Unit (CU)]].

# Registers

A register is a small-capacity, very fast storage location available within the [[Control Unit (CU)|CU]] used to store data temporarily during the execution of programs. It can hold instructions, storage addresses, or [[Data Types|data]]. There are the following registers:

- [[Instruction Register (IR)]].
- [[Program Counter (PC)]].
- [[Memory Address Register (MAR)]].
- [[Memory Data Register (MDR)]].
- [[Accumulator (AC)]].

# Buses

A bus is a shared communication pathway which transfers data between components in a computer. Buses connect with a CPU and other components. They include the following:

- [[Control bus]].
- [[Data bus]].
- [[Address bus]].

> [!info] Direction
> Buses can be monodirectional and bidirectional. That is to say, one-way communication, or two-way.

# Cores

Each processing unit is called a core. For each core, you can do a task. Having more cores means more power. Usually, CPU cores are in the following categories:

- **Single-core processors:** It can only do one task at the time. Struggles with [[Parallel processing|parallel processing]]. Common in old machines, but outdated [[Architecture|architecture]] nowadays.
- **Multi-core processors**: It has two or more cores to run instructions simultaneously, and allows for pipelining. Faster and great for multitasking and gaming.
- **Co-processors:** Is a processor designed and specialized to do a specific task really fast, such as graphics [[Rendering|rendering]].
