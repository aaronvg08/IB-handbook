A trace table is a type of diagram we use to detail what happens to variables in algorithms as they go on. A trace table is a complementary to an algorithm, whether it is in the form of a [[Flowcharts|flowchart]] or [[Pseudocode|pseudocode]].

# Example

Consider the following algorithm. It is given in the form of a flowchart.

![[basic algorithm 1.png|center|300]]

This algorithm's trace table is the following.

| i   | A   |
| --- | --- |
| -   | 1   |
| 1   | 1   |
| 2   | 2   |
| 3   | 6   |
| 4   | 24  |
| 5   | 120 |

>[!warning]
>Don't be fooled! Trace tables can get complex quite easily.
