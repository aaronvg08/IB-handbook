A mesh topology is a type of [[Architecture|network architecture]] in which all nodes are connected amongst each other. It is usually indicated for systems where the nodes must be communicated at all times. 

![[mesh topology.png|center|450]]

- **Reliability**: Robust against failure since it is a [[Distributed system|distributed system]].
- **Bandwidth**: High, but depends on devices.
- **Scalability**: High, but is quite expensive.
- **Collisions**: Minimal risk, connection per node.
- **Cost**: High because of connection.

>[!note]
>This is common in aviation and the military.
