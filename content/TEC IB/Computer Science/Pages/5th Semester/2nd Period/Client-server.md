The client-server architecture is a way to view how [[Networks|networks]] and their applications work.

- **Client**: A device or program that initiates requests for services or resources.
- **Server**: A powerful computer or program that provides resources or a service to clients.

# Benefits

- **Centralized control**: Easy to manage since it is a [[Distributed system|centralized system]].
- **Scalability**: Easier to add resources to the center.
- **Efficiency**: The server is usually very optimized to do one thing.
- **Security**: Easy to manage risks.

# Drawbacks

- **Single point of failure**: When the server dies, everything dies.
- **Single point of risk**: No security means exposure.
- **Costs**: Significant cost to meet the demands.
