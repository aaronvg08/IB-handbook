# Definition

> _“A problem is a situation that needs attention and needs to be dealt with or solved.”_

# Decision making process

- Every time you need to solve a problem, you have to make a decision according to these steps.
- Sometimes a person finding a solution to a problem must return to a previous phase and improve the outcome before proceeding to the next phase.

## Problem

- **Identification**
	- Identify the problem
    - Understand the problem
    - Formulate the problem
- **Development**
    - Create a solution
    - Create another one
- **Selection**
    - Select the best solution
    - Still theoretical
- **Implementation**
    - Did your solution work?
    - Is there a better way to do it?

# Mathematical unsolved problems

There are many mathematical problems that remain unsolved. Some of these problems include:

- The Goldbach conjecture
- The Riemann hypothesis
- The Collatz problem.
- Etc.

# Programming and solving problems

- Programming involves creating a series of steps that will solve a problem. It is a process of solving a problem in phases.
- It is very important to understand that computers can only solve problems that are solvable by humans, but also that. computers can’t solve some problems solvable by humans.
- A computer program is a sequence of instructions that explains to the computer how to solve a specific problem.
