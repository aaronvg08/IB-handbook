# Definition

> _“An algorithm is a series of unambiguous instructions designed in order to solve a problem and achieve a certain goal in a finite number of steps.”_

-IBO

# Properties

## Finiteness

An algorithm must always terminate after a finite number of steps… a very finite number, a reasonable number.

> [!important] Despite having a finite number of steps, it may not always end anyway.

## Input

Quantities which are given to it initially before the algorithm begins. These inputs are taken from specified sets of objects.

## Effectiveness

All of the operations to be performed in the algorithm must be sufficiently basic that they can in principle be done exactly in a finite length of time by a man using pen and paper.

## Definiteness

Each step of an algorithm must be precisely defined; the actions to be carried out must be rigorously and unambiguously specified for each case.

## Output

Quantities which have a specified relation to the inputs. What the algorithm returns.

# Algorithms as problem-solvers

- The harder the problem, the bigger and more complicated the algorithm will be.
- It is very important to understand that writing an algorithm is in essence, just problem solving.

# Expressions

An algorithm may be expressed in a number of ways, including:

- Simple english/spanish (natural language)
	- Not very common because it is usually verbose and ambiguous.
- [[Flowcharts]]
	- A formalized graphic representation method which avoids _**most**_ issues of ambiguity.
- [[Pseudocode]]
	- Is a generic artificial language that describes computer algorithms but doesn’t use the syntax of any particular programming language. Pseudocode may often contain natural language to describe various parts of an algorithm. These parts, written in natural language, are later replaced.
- Programming language
	- Is an artificial language designed in such a way so that it may be used by humans in order to communicate with a computer system. Various programming languages exist that may be used for different purposes or problems.

> [!important] This list goes from more ambiguous, to less!
