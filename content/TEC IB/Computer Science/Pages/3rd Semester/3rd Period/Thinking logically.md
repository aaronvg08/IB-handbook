Sometimes, some problems require the use of decisions. Some don't. The addition process, for instance, doesn't require any decision to be taken. The following algorithm is straight-forward:

```pseudocode
Input A
Input B
C=A+B
Output C
```

However, some do require some thinking other than just following instructions. Suppose there is a pedestrian crossing that is equipped with a light signal. If the signal is green, then crossing the road is safe and the pedestrian can walk across. If the signal is red, then the pedestrian should stop and wait. 

The following [[Flowcharts|flowchart]] illustrates what the algorithm corresponds to in this scenario.

![[thinking logically.png|center|600]]

Doing this kind of decision-making usually involves some kind of if condition. So, a [[Boolean operators|boolean operation]]. 

>[!note]
>It to think that these conditions are obvious, but the very essence of programming is translating these rules we can infer into code.
