Iteration in [[Computer Science|computer science]] is the process of repeating a series of instructions. It is extremely useful in programming and is used to repeat a statement or a block of statements within an algorithm.

```python
x = 0
for i in range(10):
	x + 1

print(x)
```

```python
x = 0
while x < 10:
	x + 1

print(x)
```

>[!note]
>Iteration is normally expressed using for and while loops.
