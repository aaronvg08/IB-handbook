Mathematical modelling refers to a process where a system is understood well enough and scientists describe it using a mathematical language. A set of mathematical rules is used to describe the function of the particular system.

Mathematical models are usually run through a computer to make it faster to iterate through, or do them a bunch of times. That is called simulation!
