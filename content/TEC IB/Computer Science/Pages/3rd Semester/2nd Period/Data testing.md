This is a way of doing [[Testing|testing]] for a program in an organization. Data testing is when normal, abnormal, and extreme date is put into a system to see if the system is able to handle it. Suppose that there is a program that accepts a student’s percentage and gives a ‘pass’ if the number is greater than or equal to 60, otherwise it prints a ‘fail’ message. Here, you should test:

- **Normal data:** Such as 75.
- **Data at the limits:** Such as 0, 59, 60, 100.
- **Extreme data:** Outside normal limits, such as: -10, 104, 1223.
- **Abnormal data:** Data that isn’t expected, such as: “two”, “4 5”
