Software deployment is when a company, organization, or an individual finally releases their product for others to use. It is a milestone and the completion (or at least temporary completion) of the engineering cycle.

# Updates and release management

Okay, but now that your app is online, it needs to be updated. There are several ways in which updates can be made available. There are automatic updates that function through the net. These types of updates usually aim to improve the product, fix deficiencies, or perform changes. When the company decides that it no longer wishes to support software and wishes to promote a newer version, it stops releasing updates.

- **Patches** are used by software companies to update applications by fixing known bugs and vulnerabilities. These may introduce new bugs as side effects (lol).
- **Upgrades** always contain novel functionalities or characteristics, as well as cumulative bug fixes. Most updates need to be bought.
- **Updates** improve a product in a minor way to by adding new functionalities or fixing known bugs. Most updates are free.
- **Releases** are final, working versions of software applications. These have already gone through alpha and beta software testing. Releases relate to new/upgraded applications.
