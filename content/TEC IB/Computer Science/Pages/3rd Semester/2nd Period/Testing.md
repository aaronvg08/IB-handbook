Testing is the process of testing a program in an organization and making sure that it works and meets all the success criteria. It is the main way to find out if the program or solution needs to undergo changes (again) or if the current version is good enough to be the one to be used.

# Types

There are multiple ways to test if a program is viable or not. Here are some of those ways:

- [[Functional testing]]
- [[Alpha testing]]
- [[Data testing]]
- [[Dry-run testing]]
- [[Unit testing]]
- [[Integration testing]]
- [[User acceptance testing]]
